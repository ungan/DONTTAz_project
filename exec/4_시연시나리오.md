# Donttaz 앱 시연 시나리오

본 문서는 Donttaz 앱 시연(Demonstration)을 위한 화면별 흐름, 실행 클릭 위치 및 주요 기믹에 대한 상세 설명서입니다. 
시연 전, 모바일 디바이스 또는 시뮬레이터(Expo Go)와 BE 백엔드 서버가 켜져 있어야 합니다.

---

## 단계 1 : 진입 및 소셜 로그인 (Onboarding)

### 1) 인트로 (Splash & Login) 화면
- **실행/화면 설명**: 사용자가 앱을 처음 켜거나 미인증 상태일 때 진입하는 화면입니다. 돈땃쥐 마스코트가 메인으로 배치되어 있습니다.
- **클릭 위치 및 액션**: 화면 중앙 하단의 `[ 카카오 로그인 ]` 노란색 버튼 클릭
- **백그라운드 처리**: 카카오 OAuth 창이 호출되어 계정 권한 동의 절차 수행 -> BE 서버 거쳐 앱 내부 세션 진입

---

## 단계 2 : 홈 화면 및 금고 연동 (Home Dashboard)

### 1) 메인 대시보드 (Home)
- **실행/화면 설명**: 사용자의 총 자산 현황과 보유한 '위시(목표) 금고' 목록이 최상단에 스크롤 형식(위젯)으로 나타납니다.
- **클릭 위치 및 액션**: 
  - 화면 중앙 `[ 내 주계좌 연동하기 ]` 클릭 (최초 1회 한정) -> 가상 핀테크 금융망 계좌 번호 입력 및 핀테크 API 연동 승인 완료
  - 연동 이후에는 화면 우측 하단의 `[ + 금고 추가 ]` Floating 버튼 클릭

---

## 단계 3 : 금고 생성 및 입찰 (Create Vault & Deposit)

### 1) 금고 개설 화면
- **실행/화면 설명**: 목적별(여행, 맥북 구매, 적금 등) 금고를 여러 개 제한 없이 생성할 수 있는 페이지입니다. (모계좌 구조 덕분에 무제한 생성 가능)
- **클릭 위치 및 액션**: 
  - 목적 텍스트 필드 탭 -> "오사카 여행" 타이핑
  - 금액 목표 설정 탭 -> "1000000" 타이핑
  - `[ 완료 ]` 버튼 클릭 
- **설명 포인트(시연자 멘트)**: *"저희 서비스는 내부 DB에서 논리적으로 금고를 분할 관리하므로 20일 계좌 개설 제한 규제 없이 마음껏 금고를 생성할 수 있습니다."*

### 2) 금고 입금 (상세 페이지 - 모계좌 연동)
- **실행/화면 설명**: 방금 만든 금고 리스트 카드를 누르면 상세 뷰로 진입합니다.
- **클릭 위치 및 액션**: `[ 이체(입금) 하기 ]` 버튼 클릭 -> 금액 다이얼 '500,000' 입력 -> 하단의 `[ 확인 ]` 버튼 클릭
- **백그라운드 처리**: 주계좌에서 출금되어, 서버의 '모계좌'로 즉시 이체(금융망 API) 및 앱 내 금고 DB 테이블 +500,000원 처리 반영 완료 (시퀀스 다이어그램 로직)

---

## 단계 4 : AI 소비 코멘트 시연 (Features)

### 1) 소비 리포트 메뉴 
- **실행/화면 설명**: 하단 내비게이션 바(Tab 바)에서 두 번째 아이콘인 `[ 리포트 ]` 클릭
- **클릭 위치 및 액션**: 
  - 화면 상단의 `[ 이번 달 AI 분석 리포트 생성 ]` 클릭 
- **실행 결과**: LLM API와 통신하여, 앱에서 결제한 내역 위주로 “최근 카페 방문율이 높아 금고 목표에 차질이 생길 수 있습니다!”라는 식의 스마트 알림 모달 출력

---

## 단계 5 : 목표 달성! 금고 해지 및 외부 웹훅 발송 (Webhook / Withdraw)

### 1) 금고 출금(만기)하기 (Vault Detail)
- **실행/화면 설명**: 목표 100만 원짜리 금고에 100만 원 전체 입금이 달성된 상태를 가정 (금고 상세 페이지)
- **클릭 위치 및 액션**: 
  - 100% 달성 시 활성화되는 `[ 보상 받기(출금) ]` 텍스트 버튼 클릭
- **백그라운드 처리**: 이자 계산 과정을 거쳐, 서버의 '모계좌'에서 사용자의 '주계좌'로 원금+이자가 핀테크 API 로직을 타고 되돌아옴.

### 2) RabbitMQ 비동기 웹훅 모니터링 (Discord 화면 전환)
- **실행/화면 설명**: 출금 완료 시점에 돈땃쥐 외부 Discord 앱 모니터링 화면으로 전환
- **설명 포인트(시연자 멘트)**: *"방금 금고 달성 축하 이벤트가 발생하면서 Discord/Mattermost 웹훅으로 알림이 전송되었습니다. 해당 알림 전송 로직은 무거운 외부 통신이므로 RabbitMQ 비동기 큐를 적용하여 1초씩 걸리던 지연 시간을 0.05초 미만으로 단축하여 유저 체감 성능(UX)을 대폭 상승시켰습니다."*
- **실행 결과**: Discord 모니터링 채널에 "[축하합니다] 사용자님의 모계좌를 통한 금고 입출금 과정이 정상 처리되었습니다" 메시지 노출 확인
