# 프로젝트 외부 서비스 통합 정보

본 문서는 Donttaz 애플리케이션 서비스 동작을 위해 가입, 연동 및 설정이 필수적인 주요 **외부 클라우드 서비스 및 Open API 플랫폼** 목록입니다. 프로젝트 셋업 과정에서 해당 서비스의 콘솔에 접속하여 Key를 발급받아 환경 변수(`.env`)에 주입해야 합니다.

---

## 1. 카카오 소셜 인증 (Kakao Developers)
앱 진입 시 카카오 OAuth 2.0 기반으로 로그인을 처리합니다. 사용자 프로필(회원번호 등)을 받아와 내부 회원 토큰(JWT) 교환에 사용합니다.
- **용도**: 애플리케이션 시작 및 사용자 회원가입 / 로그인
- **필수 발급 Key**: `REST API 키` (KAKAO_CLIENT_ID), `Client Secret` (KAKAO_CLIENT_SECRET)
- **설정 유의점**: 
  - Kakao Developers 내 도메인 화이트리스트 및 `Redirect URI` 등록 필수
  - 팀원 간 앱 테스트 시 카카오 Developers 내에 테스터 아이디 사전 등록 권장

## 2. 핀테크 금융망 API (핀테크 플랫폼)
가상의 모계좌 은행 시스템과 사용자의 실물 계좌 이체, 잔액 정보 연동 등에 사용됩니다.
- **용도**: 
  - 외부 은행 -> 앱 주계좌로 돈 입금 
  - 앱 모계좌 -> 앱 주계좌로 자금 재배분 (금고 입출금용 백엔드 원장)
- **필수 발급 Key**: `FIN API Key` 등
- **설정 유의점**: 
  - 통신 암호화를 위해 핀테크 API 제공 정책에 맞춰 Header 또는 JWT를 서명해서 전송하는 파트가 있으니 플랫폼 가이드 준수

## 3. Firebase Cloud Messaging (FCM)
금고 입금, 이자 지급(만기), 혹은 AI 코멘트 도달 등 사용자 스마트폰으로 Push 알림을 전송할 때 사용합니다.
- **용도**: 앱 백그라운드 푸시 네트워크 연결 (AOS, iOS 공통 처리)
- **필수 발급 Key**: `firebase-service-account.json` (프로젝트 설정 -> 서비스 계정 -> 새 비공개 키 생성)
- **설정 유의점**: 해당 JSON 파일은 Git 저장소에 절대 Commit되지 않아야 하며 젠킨스 환경 변수(Credential/Secret text 혹은 Secret file)로 안전하게 주입됩니다.

## 4. 메신저 웹훅 (Discord / Mattermost)
RabbitMQ 등과 연동되어 서비스에서 일어나는 중요 에러(Exception)나 서버 퍼포먼스(벤치마크 결과 등), 금고 이자 지급 만료 알림 모니터링에 씁니다.
- **용도**: 개발 및 운영팀 시스템 모니터링, 이벤트 알림 봇 연동
- **필수 발급 Key**: 방장/채널 관리자가 발급한 `Webhook URL` (Discord Webhook / Mattermost Webhook)

## 5. AI 지능형 코멘트 서버 / LLM 연동 (선택)
사용자 소비 명세나 금고 사용 내역을 바탕으로 코멘트나 플랜 예측 분석을 받아올 때 사용합니다. (GPT / 외부 모델 서버 활용)
- **용도**: 유저 맞춤 금융 AI 조언 메시지 
- **필수 발급 Key**: `GMS_KEY` 등
- **설정 유의점**: LLM_ENABLED 플래그를 통해 활성/비활성화 스위치가 가능합니다.

---

> ※ 포톤 클라우드, 게임엔진 컴파일 관련 등 게임 특화 서비스는 당사 핀테크 서비스 성격(Donttaz) 상 사용하지 않습니다.
