# 소비 분석 리포트 상세 명세

> `POST /reports/generate` 응답의 각 필드가 어떻게 계산되는지 설명합니다.

> **구현 주의사항**
> - `yearMonth`는 응답에 그대로 포함되는 표시용 필드이며, 현재 구현에서 거래 필터링에 사용되지 않습니다. 분석은 **입력된 거래 전체**를 대상으로 합니다.
> - 전달 비교(`previous_transactions`)는 현재 비활성 상태입니다. `SpendingAnalysisService`에 빈 배열이 전달되므로 전달 대비 증감 분석은 동작하지 않습니다.

---

## 전체 처리 흐름

```
거래 내역 입력
    ↓
1. 카테고리별 지출 집계          (SpendingAnalysisService)
2. 주차별 패턴 분석              (SpendingAnalysisService)
3. 충동소비 지수 / 위험도 산정    (SpendingAnalysisService)
4. 카테고리별 예산 달성률 계산    (build_category_reports)
5. 룰 기반 피드백 생성           (FeedbackService)
6. LLM 전체 피드백 생성          (LLMService)
7. 개인화 피드백 생성            (PersonalizedFeedbackService)
```

---

## 응답 필드별 상세 설명

### `totalBudget` / `totalSpent` / `achievementRate`

```
totalBudget     = 플랜의 totalBudget = 잔액 - 봉인금액  (봉인금액이 이미 제외된 값)
sealedAmount    = 봉인금액 (리포트에서는 참고용으로만 표시)
totalSpent      = 해당 월 카드 지출 합계
achievementRate = (totalSpent / totalBudget) × 100
```

> `totalBudget`은 "이번달 자유롭게 써도 되는 금액"입니다.
> 봉인금액은 월급일까지 건드리지 말아야 할 예비비이므로 예산 달성률 계산에서 제외됩니다.
> 100% 초과 = 예산 초과, 100% 미만 = 예산 내 관리

---

### `categoryReports` — 카테고리별 예산 달성 현황

카테고리별로 아래 값을 계산합니다.

| 필드 | 계산 방법 |
|------|-----------|
| `allocatedAmount` | 플랜의 카테고리별 배정 금액 |
| `spentAmount` | 해당 월 해당 카테고리 실제 지출 합계 |
| `categoryRate` | `spentAmount / totalSpent × 100` |
| `feedback` | 아래 규칙으로 결정 |

**`feedback` 결정 규칙:**

```
플랜 없는 카테고리에서 지출 발생   → "계획이 없던 지출 항목입니다."
spentAmount > allocatedAmount      → "계획 대비 초과 소비입니다."
그 외                              → "계획 범위 내 소비입니다."
```

---

### `aiOverallFeedback` — 전체 종합 피드백 (**LLM 생성**)

LLM(`gpt-4o-mini`)이 아래 신호들을 받아 **2문장 이내**로 생성합니다.

LLM에 전달되는 신호:

| 신호 | 내용 |
|------|------|
| `totalBudget` / `totalSpending` | 예산 vs 실제 지출 |
| `remainingBudget` | 잔여 예산 |
| `achievementRate` | 달성률 |
| `patternChange` | 주차별 소비 패턴 변화 문장 |
| `topCategory` | 가장 많이 지출한 카테고리 |
| `overspentCategories` | 예산 초과된 카테고리 목록 |
| `nightSpendingRatio` | 야간 소비 비율 (%) |
| `impulseScore` | 충동소비 지수 0~100 |
| `riskLevel` | `LOW` / `MEDIUM` / `HIGH` |

LLM 실패 또는 `LLM_ENABLED=false`이면 룰 기반 문장으로 자동 대체됩니다.

**룰 기반 fallback 예시:**
```
잔여 예산 < 0         → "이번 달 예산을 초과했습니다. 상위 지출 항목을 우선 점검해보세요."
달성률 < 30%          → "현재 소비는 안정적인 초기 단계입니다."
위험도 HIGH           → "현재 소비 위험도가 높은 상태입니다."
```

---

### `personalizedFeedback` — 개인화 피드백 (룰 기반, 최대 5개)

조건에 따라 자동 생성됩니다. 우선순위 순서:

#### 1. 예산 초과 카테고리 경고 (최대 2개)
```
조건: allocatedAmount > 0 AND spentAmount > allocatedAmount
타입: warning
예시: "식비가 계획 대비 30,000원 초과되었습니다."
```

#### 2. 주차별 소비 패턴 변화
```
조건: 패턴 변화 문장이 존재하는 경우
타입: pattern
예시: "3주차에 지출이 집중된 이후 후반부에는 소비가 감소하는 흐름을 보였습니다."
```

**패턴 변화 판단 기준:**

| 조건 | 메시지 |
|------|--------|
| 특정 주차 지출이 전체의 40% 이상 | `N주차에 지출이 집중되는 패턴` |
| 마지막 주차가 직전 주 대비 +30% | `최근 주차 지출이 크게 증가` |
| 마지막 주차가 직전 주 대비 -30% | `최근 주차 지출이 크게 감소` |
| 주차가 지날수록 단조 감소 | `점차 감소하는 흐름` |
| 주차가 지날수록 단조 증가 | `점차 증가하는 흐름` |
| 그 외 | `비교적 안정적으로 유지` |

#### 3. 가장 잘 관리된 카테고리 칭찬
```
조건: 예산 내에서 지출한 카테고리 중 예산과 실제 지출 차이가 가장 적은 것
타입: positive
예시: "교통은 계획 범위 내에서 안정적으로 관리되었습니다."
```

#### 4. 야간 소비 경고
```
조건: 야간 소비 비율 >= 15%
타입: pattern
예시: "야간 소비 비중이 높았습니다. 늦은 시간 결제를 줄이면 변동지출 관리에 도움이 됩니다."
```

## 내부 분석 지표 (응답에 직접 노출되지 않지만 피드백 생성에 사용)

### 충동소비 지수 (`impulseScore`, 0~100)

```
score = (0.4 × 야간소비비율) + (0.4 × 재량지출비율) + (0.2 × 주말소비비율)
      × 100
```

- **야간 소비**: 22시~04시 사이 결제
- **재량 지출**: 쇼핑, 여가 등 필수가 아닌 카테고리
- **주말 소비**: 토~일 결제

### 위험도 (`riskLevel`)

| 조건 | 위험도 |
|------|--------|
| 충동소비 지수 ≥ 70 OR 야간소비 ≥ 30% | `HIGH` |
| 충동소비 지수 ≥ 40 OR 야간소비 ≥ 15% | `MEDIUM` |
| 그 외 | `LOW` |

## 플랜 없이 리포트 생성 시 (신규 가입자 케이스)

이번달 처음 가입한 사용자는 지난달 플랜이 없으므로 `plan` 필드 없이 리포트를 요청합니다.
이 경우 AI가 계좌 거래 내역에서 예산을 자동 추정합니다.

```
월소득 추정  = paydayDay ±3일 이내 입금 중 매달 반복되는 금액 (±20% 오차 허용)
고정지출 추정 = 계좌 출금 중 "월세", "관리비", "보험" 등 키워드 매칭
총 예산      = 월소득 - 고정지출 - 여유분(10%)
카테고리별 예산 = 실제 지출 비율 기반 배분 (데이터 부족 시 통계청 기본 비율 사용)
```

이 경우 `categoryReports[].allocatedAmount`는 AI 추정값이므로 실제 소비와 비교 시 참고용으로만 활용됩니다.
`paydayDay`를 함께 전달하면 소득 추정 정확도가 높아집니다.

## 소비 페르소나 (`spendingPersona`)

카테고리별 지출 비중을 분석해 소비 패턴을 도출합니다.

| 페르소나 | 주요 소비 카테고리 | 설명 |
|----------|--------------------|------|
| `식도락형` | 식비, 외식, 배달 | 음식 관련 지출이 집중된 패턴 |
| `쇼핑족` | 쇼핑 | 쇼핑 지출 비중이 높은 패턴 |
| `생활밀착형` | 교통, 생활 | 교통·생활 필수 지출 중심 패턴 |
| `여가충전형` | 여가 | 취미·엔터테인먼트 지출 비중이 높은 패턴 |
| `자기계발형` | 의료/건강, 교육 | 건강·교육 투자 중심 패턴 |
| `재무관리형` | 금융/보험 | 금융·보험 지출 비중이 높은 패턴 |
| `균형소비형` | (특정 카테고리 없음) | 특정 카테고리 집중 없이 고르게 소비 |

> 데이터가 부족하거나 분석이 불가능한 경우 `"분석불가"` 또는 `"데이터부족"`이 반환되며, 이 경우 페르소나 관련 피드백은 생략됩니다.
